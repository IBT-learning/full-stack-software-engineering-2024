# React To-Do App

A simple and interactive to-do list application built with React. This app allows users to add tasks, mark them as completed, and visually distinguish between completed and pending tasks.

## Features

- Add tasks to your to-do list using a text input field.
- Mark tasks as completed with a single click.
- Visually identify completed tasks with distinct styling.
- Persistent and dynamic UI updates.
